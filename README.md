# Duhuza ❤️
Mobile-first 18+ matchmaking web app. Features registration/login, profiles, discover, likes/matches, chat, block/report, SQLite database and PWA install support.

Run: `npm install` then `npm start`, open `http://localhost:3000`.

Demo accounts: `aline@demo.duhuza`, `eric@demo.duhuza`, `shalom@demo.duhuza` — password `demo12345`.

Before production: set a strong JWT_SECRET, add Terms/Privacy/Community Guidelines, configure real payment provider if charging users, add moderation and secure HTTPS deployment.
